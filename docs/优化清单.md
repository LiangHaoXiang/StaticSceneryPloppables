## 本轮实施范围（2026-11-14）

已实施：**#1、#2、#3、#5、#6、#7、#13**（对应上表 ✅）。

预期收益：
- 启动：反射缓存后目录构建应显著下降（待实测，目标 6s → 2~3s），且每帧负载更平滑；
- 稳态：消除每秒一次的全城查询尖峰（建筑侧改为纯内存比对，地皮侧反查 30s 一次）；
- 体积：发布包去掉 pdb，164 KB → 约 85 KB；
- 内存：三个跟踪表加剪枝，长局不再缓慢上涨。

验证要点：载入 → 面板条目 2077 → 放置/迁移/拆除（地皮不残留）→ 存读档 → 长局观察内存与帧率。

实施细节与实测：

- **#1** `FieldsCache`（类型 → 字段数组，含继承链一次展开）；`CopyFields` 不再每次 `GetFields`。
- **#2** 每帧预算：最多 40 个且最多 ~3ms（`FrameBudgetMs`，至少 4 个后再检查时间）。
- **#3** 进度日志改为每 500 条一条（原每 40 条，载入期 80+ 行）。
- **#5/#6/#7 → 最终决定：整体移除残留检查**（用户判断：旧残留源于「放置与迁移两套地皮生成逻辑」，现已同源，线上用户不会有图章时代残留存档）。
  - 删除内容：`CleanupOrphans` / `SeedTrackedBuildings` / `SweepOwnedAreas` / `QueueDelete(IfOrphaned)` / `TrackBuilding` / `RegisterCreatedBuildings` / `PruneTrackingTables` / `VerdictOnce` / `TryAreaCentroid` / `LogSweepSummary`，以及全部追踪表、缓冲、`Created` 查询、`DeployedArea` 查询；
  - `SceneryPloppableUISystem.Diagnostics.cs` 由 **994 行降到 341 行**，只剩默认关闭的实体树 dump；
  - 保留 `SSPDeleteInXFrames` 组件与 `HandleSSPDeleteInXFramesSystem`：仅为了兼容旧存档里已挂该组件的实体（新代码不再添加它），成本为空集合查询；
  - 稳态：**零全城查询、零追踪表**，`OnUpdate` 只剩绑定推送与工具取消联动。
- **#4** L2/L4 完全不建：`ScanSources` 里按 `SpawnableBuildingData.m_Level` 直接跳过（`BuildFor` 保留兜底判断），因此不再克隆、不再注册 prefab、不再写 `Assets.NAME` 词条。
- **#13** 部署目录剔除 pdb（dll 保留）→ 部署/发布包 **166 KB → 87.8 KB**。
  踩坑：`DebugType=none` 会让 Unity Entities ILPP 失败（`AssemblyDefinitionFor` 需要 pdb）。
