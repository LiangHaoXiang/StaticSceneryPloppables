## 五、排序规则（`GrowableVariantSystem.CatalogComparer`）

目录构建完成后在 C# 侧排序一次，UI 收到的即最终顺序（`select` 索引仍等于数组下标）。

1. **分区**：居民区 → 混合居民区 → 商业区 → 办公区 → 工业区 → 未知分区
2. **密度**：无密度 → 低密度 → 中密度 → 高密度
3. **占地总面积**（面宽×进深）：小 → 大
4. **面宽**：小 → 大
5. **进深**：小 → 大
6. **等级**：无等级（0）最前，之后等级升序
7. **标志性建筑**：常规在前、标志性在后（当前目录不含标志性建筑，此级恒等）
8. **名称自然顺序**：字母不区分大小写（a 在 b 前）、连续数字按数值（1 在 2 前、2 在 10 前）
9. 完全相等时按内部名兜底，保证顺序稳定

## 六、页签与筛选

- **页签**：全部 / 住宅 / 混合型住宅 / 商业 / 办公 / 工业
  - `住宅` 只显示纯住宅（`IsMixed == false`）；`混合型住宅` 只显示混合型
  - 判定同游戏 `PropertyUtils.IsMixedBuilding`：住宅属性 > 0 且可售卖或可制造
- **筛选面板**：风格（全部 / 欧美 / 北美）→ 密度 → 等级 → 面宽 → 进深
  - 风格归类：优先 `ThemeObject.m_Theme`（名字或 `assetPrefix` 含 Europe/North、EU/NA），其次 prefab 名 `EU_`/`NA_` 前缀；都没有的条目只出现在「全部」

## 七、实测结论与坑位

- **换档不重建**：同一进程内「进图 → 回主菜单 → 读另一存档」后，日志仍只有一套 `OnLoad` / `scan done 2077` / `BUILD COMPLETE 2077`，之后放置正常。说明 CS2 读档不重建 World/prefab，静态 `Catalog` 与运行时 prefab 持续有效 → 不存在条目翻倍或已放置建筑白模；`BuildComplete` 静态为 true 也无需重置。
- **启动期只有一次**：每次启动游戏后首次进图约 4–5 秒目录构建，换档没有第二段等待。
- **客户端补丁坑（0.1.4 首装）**：曾出现「6 个 SVG 平铺在包根、`images/` 缺失」。服务端清单 `.cpatch/**/complete/manifest` 写的是 `images\...` 且哈希与构建产物一致 → 发布无误，是启动器打补丁错层。修复：删 `pdx_mods\167410_x` → 若索引仍记「已安装」则从 `pdx_mods_cache.json` 移除该 id 记录（先备份）→ 重开启动器重新完整下载。
- **网络**：本机到 `mods.paradoxplaza.com` / `cdn.paradoxplaza.com` 的 DNS 间歇性失败，表现为启动器 `error-downloading-metadata` 并回退删除已装版本，与本模组无关。
